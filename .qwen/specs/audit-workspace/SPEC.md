# SPEC: 审核工作台页面

> 功能名称: audit-workspace
> 创建时间: 2026-04-11

## 用户故事

- 作为**审核员**，希望**进入工作台后看到清晰的页面结构和导航**，以便**快速找到需要的功能模块**
- 作为**管理员**，希望**工作台有统一的设计风格**，以便**后续扩展各子模块**

## 验收标准 (Definition of Done)

### 机器标准 (Layer 1)
- [ ] TypeScript 无 `any` 类型，严格模式通过
- [ ] ESLint 无 error 级别问题
- [ ] 页面能正常渲染，无控制台报错

### 语义标准 (Layer 2)
- [ ] **路由结构**: 工作台页面按业务模块划分目录
- [ ] **占位页面**: 每个子模块有基础占位页面（显示模块名称和待开发提示）
- [ ] **导航菜单**: 侧边栏菜单能正确跳转到对应页面
- [ ] **布局一致**: 所有工作台子页面共享统一的 header + content 布局

## 页面目录结构

```
src/app/(main)/
├── page.tsx                  # 工作台首页（已存在，统计卡片 + 快捷操作）
├── layout.tsx                # 工作台布局（已存在，侧边栏 + 顶栏）
├── tasks/                    # 审核任务模块
│   ├── page.tsx              # 任务列表页（占位）
│   └── [id]/                 # 任务详情页
│       └── page.tsx          # 任务详情（占位）
├── ai-review/                # AI 审核模块
│   └── page.tsx              # AI 审核面板（占位）
├── manual-review/            # 人工复审模块
│   └── page.tsx              # 人工复审面板（占位）
├── focus-review/             # 审核沉浸页（专注审核模式）
│   └── page.tsx              # 沉浸式审核界面（占位）
├── history/                  # 审核历史模块
│   └── page.tsx              # 审核历史列表（占位）
├── stats/                    # 统计数据模块
│   └── page.tsx              # 统计面板（占位）
└── settings/                 # 设置模块
    └── page.tsx              # 设置页面（占位）
```

## 边界情况

- **访问不存在的路由**: 显示 404 页面
- **加载中状态**: 页面切换时显示 loading 指示器

## 非功能性需求

- **性能**: 页面切换无明显卡顿
- **一致性**: 所有子页面使用相同的布局组件

## 📋 安全规则 (固化自 docs/SECURITY.md)

- 所有敏感信息必须存储在 `.env.local` 文件
- 使用 Zod 验证所有用户输入
- XSS 防护: 不直接使用 `dangerouslySetInnerHTML`
