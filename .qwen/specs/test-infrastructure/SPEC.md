# SPEC: 测试基础设施

> 功能名称: test-infrastructure
> 创建时间: 2026-04-11

## 用户故事

- 作为**开发者**，希望**项目有完整的测试基础设施**，以便**每次开发都能自动验证代码质量**
- 作为**QA**，希望**有标准化的 E2E 测试流程**，以便**自动化验收每个功能**

## 验收标准 (Definition of Done)

### 机器标准 (Layer 1)
- [ ] TypeScript 无 `any` 类型，严格模式通过
- [ ] ESLint 检查无 error 级别问题
- [ ] 单元测试框架配置完成 (Vitest/Jest)
- [ ] E2E 测试框架配置完成 (Playwright)
- [ ] `pnpm test` 能运行单元测试
- [ ] `pnpm test:e2e` 能运行 E2E 测试

### 语义标准 (Layer 2)
- [ ] **单元测试**: 核心工具函数有测试覆盖 (http-client, store)
- [ ] **E2E 测试**: 首页能正常访问
- [ ] **E2E 测试**: 点击"进入审核工作台"能跳转到 `/tasks`
- [ ] **E2E 测试**: 侧边栏菜单能正确跳转

## 🧪 E2E 测试用例 (QA 验收自动运行)

### E2E-1: 首页访问和导航
- **前置条件**: 开发服务器已启动 (`pnpm dev`)
- **操作步骤**: 
  1. 打开 http://localhost:3000
  2. 验证页面显示 "Oriole 内容审核平台"
  3. 点击 "进入审核工作台" 按钮
- **预期结果**: 
  - 页面跳转到 `/tasks`
  - 显示 "审核任务列表" 占位页面

### E2E-2: 侧边栏导航
- **前置条件**: 在 `/tasks` 页面
- **操作步骤**: 
  1. 点击侧边栏 "AI 审核" 菜单
  2. 点击侧边栏 "审核历史" 菜单
- **预期结果**: 
  - 点击 "AI 审核" 后跳转到 `/ai-review`
  - 点击 "审核历史" 后跳转到 `/history`
  - 对应菜单项高亮

## 边界情况

- **服务器未启动**: E2E 测试应给出明确错误提示
- **页面加载超时**: E2E 测试应有超时处理

## 非功能性需求

- **性能**: 单元测试运行时间 < 10s
- **安全**: 测试中不硬编码密钥

---

## 📋 安全规则 (固化自 docs/SECURITY.md)

- 所有敏感信息必须存储在 `.env.local` 文件
- 使用 Zod 验证所有用户输入
- XSS 防护: 不直接使用 `dangerouslySetInnerHTML`
