# 全局工具使用规范

## 核心原则

### 1. 工具使用铁律
- **先读后写/先查后做**：操作前必须获取最新状态
- **禁止盲目重试**：失败后分析原因，不要重复相同操作
- **失败 2 次立即停止**：执行诊断命令确认状态

### 2. 上下文管理
- 文件读取使用 `@file-reader` Skill
- 大文件（>5KB）需用户确认是否展示
- 网页读取由主代理直接 `web_fetch` 处理

### 3. 文件操作
- 编辑前必须 `read_file` 确认最新内容
- `old_string` 必须与文件完全匹配
- 删除/移动前确认目标存在

### 4. 命令执行
- 修改文件系统的命令必须先解释再执行
- 避免使用交互式命令
- 后台运行长时任务（使用 `&`）

### 5. 可观测性 (Observability)
- **记录日志**: Agent 的工具调用必须被记录，方便调试和审计。
- **流式输出**: 长时任务应使用流式 JSON 输出 (`stream-json`)，以便实时监控。
- **日志位置**: 项目级日志存储在 `.agent-logs/` 目录下。
- **日志内容**: 包含时间戳、Agent 名称、工具名、输入/输出摘要。
- **实时查看**: 使用 `tail -f .agent-logs/current.log` 查看 Agent 实时活动。
