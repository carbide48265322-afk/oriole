# Ralph 循环文档

> 自动迭代修复机制

## 🔄 什么是 Ralph 循环？

Ralph (Recursive Automated Learning Helper) 是一个自动迭代修复循环。它会：

1. 运行质量门禁 (`verify.sh`)
2. 如果失败，分析错误
3. AI 自动修复问题
4. 重复步骤 1-3，直到通过或达到最大迭代次数

## 🚀 使用方式

### 基本用法

```bash
bash scripts/ralph-loop.sh
```

默认最多运行 3 次迭代。

### 自定义迭代次数

```bash
bash scripts/ralph-loop.sh 5  # 最多 5 次
```

## 📊 工作流程

```
┌─────────────────────┐
│  运行质量门禁        │
│  (verify.sh)        │
└──────────┬──────────┘
           │
    ┌──────▼──────┐
    │ 通过？       │
    └──┬──────┬───┘
       │      │
      是      否
       │      │
       │      ▼
       │   分析错误日志
       │      │
       │      ▼
       │   AI 自动修复
       │      │
       │      ▼
       │   迭代次数 +1
       │      │
       │      ▼
       │   达到上限？─── 是 ───→ 失败，手动介入
       │      │
       │     否
       │      │
       └──────┘
          循环
```

## 💡 最佳实践

### 何时使用 Ralph 循环

- ✅ 代码规范问题 (lint 错误)
- ✅ TypeScript 类型错误
- ✅ 简单的架构违规
- ✅ 缺少错误处理

### 何时不适合使用

- ❌ 复杂的功能 bug
- ❌ 设计缺陷
- ❌ 需求理解错误
- ❌ 数据库迁移问题

## 🔧 配置

### 修改默认迭代次数

编辑 `scripts/ralph-loop.sh`:

```bash
MAX_ITERATIONS=${1:-3}  # 改为默认 5 次
```

### 失败日志

失败日志保存在 `/tmp/ralph-output.txt`，可用于分析。

## 📈 监控

### 查看历史失败

```bash
cat .agent-logs/ralph-failures.log
```

### 自动进化

Ralph 循环会与 `self-evolve.sh` 配合，自动分析失败模式并优化规则。

## ⚠️ 注意事项

1. **不是万能的**: Ralph 适合修复简单、重复性问题
2. **需要人工审核**: 自动修复后仍需人工审查
3. **避免无限循环**: 设置合理的迭代次数上限
4. **记录失败模式**: 失败日志用于后续分析和规则进化

## 🔗 相关脚本
